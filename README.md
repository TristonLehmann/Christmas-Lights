# Christmas Lights

A project idea from [florinpop17](https://github.com/florinpop17/app-ideas/blob/master/Projects/1-Beginner/Christmas-Lights-App.md).

Simulates a string of Christmas lights.

## User Stories
- [x] User can press a button to start and stop the display
- [x] User can change the interval of time controlling the change in intensity
